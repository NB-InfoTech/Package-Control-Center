## Release Process

1. **Build**: `npm run build` compiles main process (TypeScript) and renderer (Vite)
2. **Generate Installer**: `.\generate-installer.ps1` (requires Administrator PowerShell)
3. **Artifact Organization**: Script moves/renames files to `release\` folder
4. **Verification**: Check all artifacts present in release folder
5. **Cleanup**: Remove temporary `dist/electron/win-unpacked` and config files

## Verification Commands

### Check Release Folder Contents
```powershell
Get-ChildItem release\ | Sort-Object Name | Format-Table Mode, LastWriteTime, Length, Name -AutoSize
```

### Verify Artifact Integrity
```powershell
# Verify setup installer
certutil -hashfile release\PackageControlCenter-2.0.0-Setup.exe SHA256

# Verify portable executable
certutil -hashfile release\PackageControlCenter-2.0.0-P.exe SHA256

# Verify blockmap matches
certutil -verifyblockmap release\PackageControlCenter-2.0.0-Setup.exe.blockmap
```
